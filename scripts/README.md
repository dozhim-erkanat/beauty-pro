# Скрипты импорта каталога

Разовые скрипты, которыми наполнялся каталог. Обычная работа с товарами идёт
через админку — сюда лезть нужно, только если товаров много и заводить их
руками долго.

## Что уже импортировано

| Скрипт | Бренд | Товаров | Источник |
| --- | --- | --- | --- |
| `import_cutrin.py` | Cutrin, категория BIO+ | 10 | cutrin.fi |
| `import_marmara.py` | Marmara Barber, категория Парфюмерия | 10 | marmarabarber.com |

Описания переведены на русский вручную и лежат в `data/*.json` — там же
объёмы, штрихкоды и характеристики.

## Как запустить

Скрипты идемпотентные: повторный запуск обновит существующие товары по `slug`,
а не создаст дубли.

```bash
export ANON=$(grep NEXT_PUBLIC_SUPABASE_ANON_KEY .env.local | cut -d= -f2)
export ADMIN_EMAIL=почта-администратора
export ADMIN_PASSWORD=пароль

python3 scripts/import_cutrin.py
python3 scripts/import_marmara.py
```

Скрипт логинится как администратор и работает через обычный REST API Supabase,
подчиняясь тем же политикам RLS, что и админка. Сервисный ключ не нужен.

## Картинки

В репозитории картинок нет — они уже лежат в Supabase Storage (бакет `media`,
папка `products/`). Поля `local` в `data/*.json` указывают на файлы, которые
скачивались во временную папку при первом импорте.

Если понадобится перезалить с нуля — скачайте картинки по адресам из колонки
`img` (Marmara) или по штрихкоду с сайта Cutrin, положите в `img/` рядом с
проектом и запустите скрипт.

## Цены

- **Cutrin** — цен нет: на сайте бренда это закрытый B2B-каталог. Товары
  импортированы как «Цена по запросу», проставлять нужно вручную.
- **Marmara Barber** — цены пересчитаны из турецких лир по курсу
  `1 ₺ = 9.700723 ₸` на 15.08.2026, округление вверх до 10 ₸, без наценки.
  Курс задан константой `RATE` в начале скрипта.

## Права на фотографии

Фото и тексты взяты с сайтов брендов и годятся для демонстрации. Перед
запуском для клиента нужно получить официальные материалы у бренда
(дистрибьюторам их выдают) или подготовить свои.
